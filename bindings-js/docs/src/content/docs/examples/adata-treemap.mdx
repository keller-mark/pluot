This [treemap](https://d3js.org/d3-hierarchy/treemap) displays the number of cells in each combination of categories from two `obs` columns of single-cell transcriptomics data obtained from Scanpy's [example datasets](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc68k_reduced.html).
The outer level groups the cells by cell type (`bulk_labels`) and the inner level by cell cycle phase (`phase`).
Each rectangle's area is proportional to its number of cells, and its color corresponds to its cell type.
Use the controls to reverse the order of the levels, to color by the cell cycle phase instead, or to change the tiling method.

<TreemapWrapper
    client:load
    client:only="react"

    plotId={"treemap-example"}
    plotType={"LayeredPlot"}

          layer_params: {

            groupby: ["bulk_labels", "phase"],
