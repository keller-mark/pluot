This visualization is inspired by [Valdes et al. Frontiers in Bioinformatics 2023](https://doi.org/10.3389/fbinf.2023.1154588).

The heatmap arranges the cells of single-cell transcriptomics data along a [generalized Hilbert curve](https://github.com/jakubcerveny/gilbert) that fills the rectangular plotted region.
The cells along the curve are sorted by cell type (`bulk_labels`) and then by cell cycle phase (`phase`).
Each cell is colored by its expression of the selected gene (`LYZ` by default).
Use the plot controls to choose another gene, or to color the cells by their cell type or other categorical labels instead.
When coloring by a categorical label, enable _Fade By Gene_ to also set each cell's opacity by the percentile of its expression of the selected gene among the plotted cells, using the sliders to set the percentile from which cells are drawn at each opacity (0.2, 0.6, and 1.0).
This uses the `var_percentile_opacities` layer parameter.
