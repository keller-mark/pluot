This visualization is inspired by [Valdes et al. Frontiers in Bioinformatics 2023](https://doi.org/10.3389/fbinf.2023.1154588).

The heatmap arranges the cells of single-cell transcriptomics data along a [generalized Hilbert curve](https://github.com/jakubcerveny/gilbert) that fills the rectangular plotted region.
The cells along the curve are sorted by cell type (`bulk_labels`) and then by cell cycle phase (`phase`).
Each cell is colored by its expression of the selected gene `LYZ`.
Use the plot controls to color the cells by their cell type or other categorical labels instead.
