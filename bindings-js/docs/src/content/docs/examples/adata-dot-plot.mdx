This dot plot displays single-cell transcriptomics data obtained from a Scanpy [example dataset](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc68k_reduced.html).
This plot is inspired by the [sc.pl.dotplot](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pl.dotplot.html) function.
Use the plot controls to select cell types and genes (command+click or use the shift key to multi-select).
