This violin plot displays the expression of the selected gene stratified by cell type, using a single-cell transcriptomics dataset obtained from Scanpy's [example datasets](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc68k_reduced.html).
This plot is inspired by the [sc.pl.violin](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pl.violin.html) function.
Use the plot controls to select a different gene.

<ViolinWrapper
    client:load
    client:only="react"

    plotId={"violin-example"}
    plotType={"LayeredPlot"}
    storeUrl={"https://pub-adb3658c8ed642caa534fdc612cd1c0c.r2.dev/pbmc68k.adata.zarr"}
    varNameOptions={['CST3', 'LYZ', 'C1QA', 'PSAP', 'CD79A', 'CD79B']}
    plotParams={{
      layers: [
        {
          layer_type: "AdataZarrViolinLayer",
          layer_params: {
            layer_id: "violin",
            var_name: "CST3",
            groupby: ["obs/bulk_labels"],
            orientation: "Vertical",
            cmap: "Tableau10",
          },
        }
      ]
    }}
    viewMode={"2d"}
