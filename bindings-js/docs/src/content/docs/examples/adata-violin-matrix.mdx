This violin matrix plot displays the expression distribution for multiple selected genes and cell types, using a single-cell transcriptomics dataset obtained from Scanpy's [example datasets](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc68k_reduced.html).
This plot is inspired by the [sc.pl.stacked_violin](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pl.stacked_violin.html) function.
Use the plot controls to select cell types and genes (command+click or use the shift key to multi-select).
