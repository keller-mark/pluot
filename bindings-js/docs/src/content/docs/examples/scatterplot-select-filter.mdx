This scatterplot renders 1 million points, colored by the `/n_1000000/class_labels` column (integer
values 0-4). The "Filtered labels" checkboxes control the point layer's filtering criteria: points
whose label is unchecked are omitted from rendering entirely. The "Selected labels" checkboxes control
the selection criteria: filter-included points whose label is unchecked are still rendered, but
de-emphasized. Filtering and selection are independent; a label can be selected without being
filtered-in, and vice versa.
