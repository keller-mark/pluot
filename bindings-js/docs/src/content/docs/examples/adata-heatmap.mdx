This [heatmap](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pl.heatmap.html) displays single-cell transcriptomics data obtained from Scanpy's [example datasets](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc68k_reduced.html).
Each row is a cell and each column is a marker gene.
The cells are filtered to four cell types (monocytes, B cells, NK cells, and dendritic cells) using the `bulk_labels` column of `obs`,
the colormap is normalized separately for each gene, and the cells with at least 1,000 detected genes are selected (the others are faded).
Scroll to zoom and drag to pan; the gene labels follow the camera.
