---
name: pluot-record-requirements
description: Use when implementing any feature or making any bug fix. Use when the the user asks you to implement something.
---

Record a CONCISE description describing each software requirement in the `.requirements` directory (at the root of this repository). Define a new markdown file in `.requirements` for each requirement. Write software requirements using as few bullet points as possible. Adopt the user's terminology, and mention low-level implementation details when relevant, but ensure the requirements do not reference specific code symbols or files - they should be agnostic to any specific implementation.

As soon as you have recorded the requirement(s), return to the task at hand.
